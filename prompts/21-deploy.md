# 21 — Deploy

Already in place: a playable six-room game that builds with `npm run build` into `dist`.

Do this:

- Deploy that build to Vercel as a static site.
- Use the build command `npm run build` and the output folder `dist`.
- Return the live link. Opening it should load Edict, room 1 of 6, with the sentence on the page.

Leave out:

- Do not add a server, a database, or a new game screen.
- Do not commit or push as part of this step.

Check:

- Open the live link. The room, the sentence, UNDO, and RESTART are there, and the marble still cannot be moved by the player.

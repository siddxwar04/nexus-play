# 01 — Empty room

Edict is a puzzle game. The player never moves the marble. Later, the player will change one word in a sentence, and the room will obey. Do not build that yet.

Already in place: a React + Vite app.

Do this:

- Draw one quiet geometric room with Phaser.
- Use a dark page, a simple framed floor, and the word EDICT at the top.
- Make the room fill the space under the title and resize with the window.

Leave out:

- No marble, physics, door, sentence, buttons, or sound.

Check:

- Run the dev server. The page shows only the empty room.

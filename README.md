# EVOX 1.0

React + TypeScript + Vite project setup for the EVOX 1.0 hackathon.

## Stack

- React + TypeScript
- Vite
- Tailwind CSS
- Phaser 3
- Framer Motion

## Getting Started

```bash
npm install
npm run dev
```

## Structure

```
src/
├── components/
├── pages/
├── game/
├── assets/
└── App.tsx
```

## Prompts

The `prompts/` folder holds documentation of prompts used during development.
